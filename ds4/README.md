# DS4 IA

This project is a starter workspace for AI and data-science experiments in the Leomar repository.

## Structure

- `src/ds4ia/` contains the Python package
- `pyproject.toml` configures the package
- `requirements.txt` lists the project dependencies

## Run the demo

```bash
cd /workspaces/Leomar/ds4
PYTHONPATH=src python -m ds4ia --demo
```

## Notes

The current scaffold includes a minimal example dataset and a lightweight rule-based classifier to demonstrate the project layout.
